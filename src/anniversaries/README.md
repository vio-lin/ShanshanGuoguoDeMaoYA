# 纪念日素材目录

桌面待机时若当天命中纪念日，桌宠会播放此目录下的特殊待机帧（所有宠物共用一套）。

## 配置格式

编辑 `index.json`，追加一条记录：

```json
[
  {
    "id": "bday-haha",
    "date": "06-15",
    "title": "哈哈生日",
    "description": "今天是哈哈五岁生日，桌上多了小蛋糕。",
    "frames": ["01.png", "02.png", "03.png"],
    "frameDurationMs": 280
  }
]
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，英文短横线 |
| `date` | 每年重复日期，`MM-DD` |
| `title` | 纪念日名称（面板展示） |
| `description` | 描述文案（气泡/面板展示） |
| `frames` | 待机帧文件名，放在 `assets/<id>/` 下 |
| `frameDurationMs` | 每帧毫秒数 |

## 素材规范

- 帧图放 `assets/<id>/NN.png`，512×512，透明底，与桌宠帧同一锚点/尺度
- 4–6 帧，循环播放；可含轻微呼吸/表情变化
- 不需重复做 walk/jump 等动作状态，纪念日只替换待机
- 素材后续由用户提供照片后生成（走 core-ip → 帧序列 → Apple Vision 抠图流程）

## 测试

打开「布偶小屋」面板，底部「纪念日测试」区可模拟任意日期命中，无需等到真实当天。
